## 创建账号

1. 访问平台首页，点击 **注册**。
2. 填写邮箱与密码，完成验证后即可登录。

管理员可在后台审批新用户（若组织启用了审批流程）。

## 创建组织

登录后进入 **组织** 页面：

1. 点击 **新建组织**，填写组织名称与 slug（URL 标识）。
2. 组织 slug 用于 Git 远程地址，例如 `git@host:my-org/my-project/my-repo.git`。

## 创建项目与仓库

在组织内：

1. **新建项目** — 项目用于分组多个仓库。
2. **新建仓库** — 选择可见性（私有/内部/公开），初始化 README 可选。
