## 登录与账号

**忘记密码怎么办？**

联系组织管理员重置，或使用注册邮箱的找回流程（若已启用）。

**为什么注册后无法登录？**

部分部署启用了 **管理员审批**，需等待管理员批准账号。

---

## Git 与仓库

**推送被拒绝？**

检查 SSH 密钥是否已添加、是否有仓库写入权限，以及目标分支是否受保护规则限制。

**克隆很慢？**

大仓库建议使用浅克隆：`git clone --depth 1 <url>`。

---

## 流水线

**流水线没有触发？**

确认 `.wuling-ci.yml` 已提交到默认分支或 MR 目标分支，且 webhook / 轮询配置正确。

**作业一直排队？**

可能没有匹配的在线 Runner；检查 `runs-on` 标签与 Runner 状态。
